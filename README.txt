J.A.R.V.I.S. iPhone Web App - v0.1

【この版でできること】
・近未来風のスマホ画面
・時刻と日付の表示
・簡単なコマンド応答
・ブラウザ音声読み上げ（日本語音声が端末にある場合）
・Speech Recognition対応ブラウザでの音声入力
・PWAのホーム画面追加に必要なmanifest / service worker

【重要な制限】
この初期版はデモです。ChatGPTのような自由なAI会話、オンライン検索、
PCやiPhoneの設定操作はまだ接続していません。
iPhoneのSafariでは音声認識APIが利用できない場合があります。
男性の声・低音はiOSに搭載された日本語音声に依存し、必ず指定できるわけではありません。

【iPhoneのホーム画面に追加する方法】
1. このWebアプリ一式をHTTPS対応のWebホスティングに公開します。
   例：GitHub Pagesなど。index.htmlを含むファイルを同じ公開フォルダに置きます。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」→「追加」。
4. ホーム画面のJARVISアイコンから起動できます。

ZIPを展開しただけではホーム画面アプリとしてインストールできません。
PWAのインストールにはHTTPSで公開されたURLが必要です。

【安全】
APIキーをHTMLやJavaScriptに直接書かないでください。
本格的なAI接続では、APIキーをサーバー側に保管するバックエンドが必要です。
